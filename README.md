# Semester 6 Computer Engineering Practical Repository

This repository contains the Laboratory Practice II (LP2) practicals for Semester 6 of Computer Engineering. It covers three main domains:

- **Artificial Intelligence (AI)**
- **Cloud Computing**
- **Salesforce**

## Structure

- **cloud/**: Contains projects and assignments related to Cloud Computing, including full-stack applications (frontend and backend) and cloud deployment examples.
- **LPII/**: Includes C++ assignments and other practicals for LP2.
- **Salesforce/**: Contains Salesforce-related assignments, including Apex classes and Visualforce pages.

## Purpose

This repository is designed to help students and educators understand and implement practical concepts in AI, Cloud Computing, and Salesforce as per the Semester 6 curriculum. Each folder contains code, configuration files, and documentation relevant to the respective domain.

## How to Use

1. Browse the folders to find practicals for each subject.
2. Each project contains its own README or instructions for setup and execution.
3. Use this repository as a reference for learning, teaching, or preparing for exams and lab submissions.
