# Cloud Projects - Semester 6 Computer Engineering (LP2)

This folder contains practical projects for the Cloud Computing component of Laboratory Practice II (LP2), Semester 6, Computer Engineering.

## Projects Included

- **blog-application/**: A full-stack blog application with separate backend (Node.js/Express) and frontend (React + Vite). Demonstrates REST APIs, CRUD operations, and modern web development practices.
- **Student_Record_Management_System/**: A full-stack student record management system with backend (Node.js/Express) and frontend (React + Vite). Showcases database integration, RESTful APIs, and user interface design.
- **Event_Registration_System/**: (If present) A system for managing event registrations, built with a similar full-stack approach.

## How to Run

Each project contains its own `README.md` with setup and usage instructions. In general:

1. Navigate to the project folder (e.g., `blog-application`).
2. Follow the instructions in the backend and frontend folders to install dependencies and start the servers.
3. Make sure MongoDB is running for backend projects.

## Learning Outcomes

- Understand cloud application architecture (frontend, backend, database).
- Practice deploying and running full-stack applications.
- Gain experience with REST APIs, React, Node.js, Express, and MongoDB.
